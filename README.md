# 🌌 Don't Panic! — The Hitchhiker's Guide Adventure Engine

> *"A towel is about the most massively useful thing an interstellar hitchhiker can have."*

A retro-futuristic, text-adventure engine inspired by Douglas Adams' classic *The Hitchhiker's Guide to the Galaxy* and the iconic 1984 Infocom game. Built with modern Python and formatted for an immersive CRT-terminal experience on **Streamlit**.

---

## 🚀 Features

- **Retro CRT Aesthetic**: Custom phosphor-green monochrome interface styled with terminal scanline effects and retro typography.
- **Classic Narrative Puzzles**: Experience the opening sequence—wake up hungover, secure your towel, halt Mr. Prosser's bulldozer, head to the Horse & Groom, and escape Earth's demolition.
- **Hybrid Controls**: Type full natural commands into the terminal input or use the rapid directional buttons in the sidebar.
- **Dynamic Inventory & Telemetry**: Live turn counters, pocket inventory badges, and Sub-Etha sensor status.

---

## 🕹️ How to Play

### Basic Commands
| Action | Example Commands |
| :--- | :--- |
| **Movement** | `north`, `south`, `east`, `west` (or `go north`) |
| **Examine** | `look`, `l` |
| **Pickup** | `take towel`, `get beer` |
| **Puzzles** | `lie down`, `drink beer`, `consult guide` |
| **Reset** | `restart`, `reset` |
